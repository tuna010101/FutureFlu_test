# GISAID Data Acknowledgements

We gratefully acknowledge all data contributors, including the authors and the
originating and submitting laboratories responsible for obtaining specimens and
generating and sharing influenza data through the GISAID EpiFlu database.

The contributor records used by these analyses are preserved once at the
repository root:

- [`acknowledgements/gisaid_acknowledgements_h1n1.csv`](acknowledgements/gisaid_acknowledgements_h1n1.csv)
- [`acknowledgements/gisaid_acknowledgements_h3n2.csv`](acknowledgements/gisaid_acknowledgements_h3n2.csv)
- [`acknowledgements/gisaid_acknowledgements_victoria.csv`](acknowledgements/gisaid_acknowledgements_victoria.csv)

These tables contain acknowledgement fields only. They do not contain sequence
data or raw analysis metadata. Users obtaining the underlying data must comply
with the GISAID Database Access Agreement and cite GISAID as required.
